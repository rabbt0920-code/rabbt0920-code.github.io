V2.5：新增「台灣企業美股」獨立分頁

監控清單：
TSM 台積電、UMC 聯電、ASX 日月光投控、HIMX 奇景光電、
CHT 中華電信、AUO 友達光電、IMOS 南茂科技、SIMO 慧榮科技。

分頁功能：
- 獨立於美股大型科技股排行榜與美股市場評分。
- 以美國市場代號抓取美元日線資料。
- 每檔顯示價格、漲跌幅、RSI、MACD、ADX、SMA20/50/200。
- 顯示相對 SPY 20 日強弱、20 日支撐／壓力、2×ATR風險參考。
- 收盤價、SMA20、SMA50走勢圖。
- 依技術分數及大盤環境產生規則式操作觀察。
- 顯示公司定位、產業及 Yahoo Finance 新聞標題（若有）。

部署：
1. 解壓縮 ZIP。
2. 將全部檔案及 icons 資料夾上傳至 GitHub Repository 的 003 資料夾，覆蓋同名檔案。
3. Commit changes。
4. Actions → Daily US Market Analysis V2 → Run workflow。
5. 綠色勾勾成功後，重新整理網站或關閉再開啟 PWA。

資料與限制：
- 代號以美國市場實際交易標的為準；TSM、UMC、ASX、CHT 為 NYSE ADR/ADS，HIMX、AUO、IMOS、SIMO 為美國市場交易標的。
- 本分頁以 Yahoo Finance/yfinance 資料為主，可能延遲、缺漏或調整。
- 美股 ADR/ADS 報價為美元，不等於台股普通股價格；須留意匯率、交易時段、存託比例與費用。
- 操作建議是技術規則觀察，不是個人化買賣指令；未納入完整財報估值、法人預估、重大事件驗證與使用者成本基礎。
- 無法取得資料的股票會略過並列入 errors，不會以台股報價補值。
